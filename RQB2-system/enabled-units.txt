# systemd units enabled on every RasQberry image (#294). One per line.
# The image build enables all of them; "Update from GitHub Branch" enables a
# listed unit only when it is new on the device, so a unit the user turned off
# stays off. Units shipped disabled on purpose are NOT listed:
#   rasqberry-led-renderer.service  (only for LED_RENDER_MODE=service)
#   rasqberry-update-poller.timer   (rig/dev tool: auto-installs dev releases)
rasqberry-firstboot.service
# Raspberry Pi Imager's OS customisation (firstrun.sh) on images without initramfs
rasqberry-imager-firstrun.service
rasqberry-boot-config.service
rasqberry-demo-cache.service
rasqberry-health-check.service
rasqberry-tryboot-retry.service
rasqberry-ab-layout.service
rasqberry-carry-over.service
rasqberry-probation.timer
rasqberry-ip-display.service
rasqberry-update-check.timer
# Wi-Fi that NetworkManager gave up on at start (need-auth with a stored password)
rasqberry-wifi-watchdog.timer
# Turns the LED panel off at shutdown (R-043)
rasqberry-led-clear.service
# Outdated bootloader firmware: System Info, checklist, one desktop notice
rasqberry-firmware-check.service
