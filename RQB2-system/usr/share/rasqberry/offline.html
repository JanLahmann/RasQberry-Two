RasQberry Two: no internet yet

This page opens instead of rasqberry.org while the Pi has no internet connection.

  • Demos: start them from the desktop icons. Demos you have already started once work offline; a first start needs internet to download the demo.
  • Connect: click the network icon at the top right and choose your Wi-Fi, or open the RasQberry Setup icon.
  • Then: open rasqberry.org. This page also does it by itself once the Pi is online.

To stop the browser opening at login: sudo raspi-config → 0 RasQberry → Browser at login.
